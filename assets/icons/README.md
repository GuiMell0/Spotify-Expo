# Ícone do aplicativo

Arquivos locais de 1024 × 1024 pixels, derivados do glifo spotify (U+F04C7) de MaterialCommunityIcons, distribuído pela dependência @expo/vector-icons que já é utilizada na interface.

- icon.png: ícone opaco sobre fundo #121212.
- adaptive-foreground.png: símbolo verde #1ED760 com margem e fundo transparente para o ícone adaptativo Android.
- adaptive-monochrome.png: símbolo branco com fundo transparente para ícones temáticos Android.

Os arquivos estão configurados em app.json. O launcher precisa de uma nova compilação nativa para incorporar o ícone. Não modificar o package Android nem a chave de assinatura para atualizar a instalação existente.

Uso acadêmico, sem vínculo oficial com o Spotify. O símbolo e a marca pertencem aos respectivos titulares.
