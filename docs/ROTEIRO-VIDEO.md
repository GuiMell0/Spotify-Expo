# Vídeo da P2 — roteiro de 4min50s

Gravar depois de instalar e conferir o APK final. Usar a conta autorizada, conexão funcionando e uma playlist local de teste que possa ser editada e excluída.

Não mostrar credenciais, tokens, .env ou o Client Secret. A demonstração deve exibir os recursos reais do aplicativo. Reservar 10 segundos de margem para o máximo de 5 minutos indicado no trabalho.

| Tempo | O que mostrar |
| --- | --- |
| 0:00–0:20 | Abrir o APK independente, entrar com Spotify ou mostrar a sessão restaurada, e apresentar as três abas. |
| 0:20–1:10 | Buscar uma música ou artista, abrir um álbum, conferir suas faixas e visitar o artista. Voltar à busca e mostrar uma playlist Spotify acessível, se disponível para a conta. |
| 1:10–1:45 | Curtir uma música, abrir Músicas curtidas, consultar Buscas recentes e repetir um termo. |
| 1:45–2:45 | Criar uma playlist local, adicionar uma faixa e abrir seus detalhes. Renomear, remover a faixa e demonstrar a confirmação de exclusão em uma playlist de teste. |
| 2:45–3:15 | Abrir Perfil, editar o apelido local e trocar grade/lista ou ordenação nas Configurações. Mostrar a Biblioteca atualizada. |
| 3:15–3:50 | Abrir uma música de um álbum, trocar a seleção pela fila, voltar e reabrir pelo mini-player. Tocar em Ouvir no Spotify para mostrar o destino da faixa. |
| 3:50–4:30 | Fechar e reabrir o app para conferir dados persistidos. Desativar a conexão, abrir uma playlist local e uma faixa salva, depois reativar a conexão. |
| 4:30–4:50 | Mostrar brevemente o repositório com o histórico de commits e identificar os integrantes. Encerrar. |

## Preparação

1. Conferir o checklist de VALIDACAO-P2.md e resolver os erros antes de gravar.
2. Ter uma playlist Spotify que a API permita abrir. Se houver acesso negado, registrar a limitação real e mostrar o tratamento de erro; não apresentar dados fictícios como API.
3. Manter uma playlist local com pelo menos duas músicas para demonstrar a fila.
4. Reservar uma segunda playlist local para a exclusão, sem apagar dados pessoais.
5. Testar a gravação de tela e usar Não perturbe para evitar notificações pessoais.
6. Fazer uma gravação de ensaio para garantir duração menor ou igual a cinco minutos.

Não é necessário aguardar o token vencer para gravar o trecho offline. O teste de restauração com token vencido faz parte da validação técnica no aparelho e do relatório, sem consumir o tempo do vídeo.

## Publicar e entregar

Publicar o arquivo em um serviço que forneça um link de visualização e testar esse link em uma janela anônima ou outra conta. Conferir que o avaliador consegue assistir sem pedir permissão.

Cada integrante deve enviar individualmente no AVA os links exigidos para presença e entrega, conforme a orientação recebida. O repositório pode ser o mesmo.
